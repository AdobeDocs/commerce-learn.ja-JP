# ストア設定とシステムメニューに移動します

商品属性のフィルタリングから、商品グリッドのカスタマイズ、ビューの保存に至るまで、Adobe Commerce管理ワークスペースを探索できます。 このビデオでは、[!UICONTROL Stores] メニューと、一般的なストア情報、カタログ設定、セキュリティ、お客様、およびセールスの設定領域についても説明します。

## この動画は誰のためのものでしょうか？

* Adobe Commerce ストアを管理する管理者とユーザー
* Adobe Commerce管理者の概要

## ビデオコンテンツ

* 固定製品属性グリッドを属性スコープでフィルタリングします。
* 列の表示/非表示を切り替えたり、列を別の順序にドラッグしたりして、商品グリッドをカスタマイズできます。
* 商品を色でフィルタリングし、フィルタリングしたグリッドを再利用可能なビューとして保存します。
* デフォルトのビューと保存されたビューを切り替え、既存のビューを更新します。
* ストア設定に移動し、一般、カタログ、セキュリティ、顧客、セールスの設定を確認します。

>[!VIDEO](https://video.tv.adobe.com/v/3473115?learn=on)

## 保存したグリッド ビュー

保存されたビューには、グリッド設定が再利用されます。 ビデオのblue-productsの例では、新しく追加された製品がフィルターに一致すると表示されます。 色が一致しなくなった場合、製品が表示されなくなります。

## ストア設定

[!UICONTROL Stores] メニューからストア設定にアクセスできます。 設定ツアーでは、店舗の場所とメールアドレス、通貨、カタログ表示設定、セキュリティオプション、顧客のデフォルト、配送方法、支払い方法などがハイライトされます。
