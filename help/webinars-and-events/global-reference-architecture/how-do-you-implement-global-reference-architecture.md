# グローバル参照アーキテクチャの実装

{{only-for-on-prem-commerce-cloud}}

グローバル参照アーキテクチャやGRAを簡単に実装する方法について説明します。 GRAを成功に導くための早期判断について説明します。 web サイトを分離する方法、成功の鍵、整理整頓して機能を開発するためのコンセプトを紹介します。

## オーディエンス

* このコンセプトを理解する必要がある人は誰でも。
* 複数のブランドを持つ大規模プロジェクト

## ビデオコンテンツ

* GRAを成功させるためには、早い段階での意思決定が必要です
* GRAでWeb サイトを配布するためのアイデア
* グローバル参照アーキテクチャプロジェクトを成功させるための鍵
* 命名規則
* 基盤となる機能に適したブランドやweb サイトを選択する
* 主な役割と責任
* グローバルコントロールボード – 取り組むべき機能
* モジュールのマーケットプレイスとしてGRAを使用するための代替コンセプト
