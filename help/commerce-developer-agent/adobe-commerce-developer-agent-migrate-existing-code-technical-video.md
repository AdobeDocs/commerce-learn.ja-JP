# Adobe Commerce Developer Agent既存のコードを移行する

すべてのプロジェクトが空の設定から始まるわけではありません。 次の例では、Migration Assessment Toolを使用してDeveloper Agentにフィードし、PaaS PlatformからAdobe Commerce as a Cloud Serviceに移行する既存の拡張機能をApp Builderに移行します。

## この動画は誰のためのものでしょうか？

* Commerce開発者
* ソリューションアーキテクト
* バックエンドエンジニア

## ビデオコンテンツ

* Migration Assessment Toolを使用した既存のCommerce インスタンスのスキャン – 複雑さの評価、モジュールごとの影響、リスクシグナル、およびリビルド、リファクタリング、置換、またはレコメンデーションの削除
* フック、ファイル、および既製のプロンプトを兼ね備えた平易な言語の目的の概要など、インパクトの大きいモジュールの評価を確認する
* 手作業でコピーすることなく、Developer Agentに評価を直接送信する
* 最初のパスを特定の機能に集中させるために、担当者のスコープに関する質問に答えます
* 最もリスクの高いレガシーロジックを置き換える同期webhookの設計図とアーキテクチャ図の生成
* 各ハンドラーと一緒に書かれた一致するテストファイルを使用して実装を構築する
