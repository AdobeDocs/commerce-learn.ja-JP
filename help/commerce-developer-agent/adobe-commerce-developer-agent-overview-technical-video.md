# Adobe Commerce Developer Agentの概要

Adobe Commerce Developer Agentは、英語の平易なリクエストを、手書きのコードを使用しない、実用的なデプロイされたストア機能に変換します。 これは、入力された命令から、実際のストアフロントでのライブテストに至るまでのジャーニー全体を追っており、Commerceのカスタム機能の構築方法が変化する理由を説明しています。

## この動画は誰のためのものでしょうか？

* Commerce開発者
* ソリューションアーキテクト
* 開発リーダー

## ビデオコンテンツ

* Commerceのカスタム機能が、従来、手書きのWebhook コード、App Builder設定、包括的なビルドテストとデプロイサイクルを必要としていた理由
* 開発者エージェントが技術的な実装（正しいWebhook メソッド、ペイロードマッピング、設定スキーマ）を平易な英語のルールから処理する方法
* 人間がデバッガーを開く前にビルドエラーを検出して修正する自動コード検証
* ストア部門がローンチ後に調整できるビジネス設定として、制限とメッセージを公開する
* ブループリント、開発、接続、デプロイ、設定、テストのチュートリアルのプレビュー
