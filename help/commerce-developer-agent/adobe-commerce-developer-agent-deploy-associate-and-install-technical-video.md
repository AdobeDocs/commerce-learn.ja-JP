# Adobe Commerce Developer Agentのデプロイ、関連付け、インストール

すべてが接続されているため、アプリは本番用に準備できます。 この段階では、コードをデプロイし、そのコードを関連付けてAdobe Commerce管理者にインストールして、ストアで新機能を有効にします。

## この動画は誰のためのものでしょうか？

* Commerce開発者
* ソリューションアーキテクト
* Commerce管理者

## ビデオコンテンツ

* 開発者エージェントにチャットからのデプロイを依頼し、正確な組織、プロジェクト、ワークスペースを確認する
* デプロイ前の検証パスを使用し、コードのデプロイ時にストリーミングビルドおよびパブリッシュ出力を渡します
* Commerce管理者のApp Management画面から、デプロイされたアプリを特定のストアに関連付ける
* アプリカードの確認：名前、バージョン、追加機能（webhook）
* アプリをインストールして機能を有効にし、正常にインストールされたことを確認する
