# Adobe Commerce Developer Agentのブループリントと開発ステージ

ブループリントと開発段階では、平易な英語のルールが、機能的で検証済みのコードになります。 Adobe Commerce Developer Agentは、カート数の制限を例として、記述されたルールをレビュー可能な正式なプランに変換し、ライブワークスペースでWebhook コードを記述して自己検証します。

## この動画は誰のためのものでしょうか？

* Commerce開発者
* ソリューションアーキテクト
* バックエンドエンジニア

## ビデオコンテンツ

* App Builderモードで、ビジネスルール（カート数の制限）を平易な言葉で説明し、ブループリントを生成する
* ブループリントと計画パネルの確認 – ランタイム選択、エンタープライズ対応チェックリスト、信頼度の見積もり
* この計画は、具体的なタスクに加え、webhookがカートの追加をどのように評価し、ブロックするかについてのロジック図に分かれています
* 開発段階では、ファイルとコードがプロジェクトエクスプローラーにストリーミングされ、プロジェクトワークスペースにコードが書き込まれます
* 自動ビルド、テスト、自己修正が行われ、担当者は一時停止して、明確化が必要なタイミングを確認します
* 生成された設定、ビジネス設定スキーマ、Webhookの詳細の検証
