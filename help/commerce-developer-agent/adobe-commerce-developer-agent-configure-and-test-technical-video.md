# Adobe Commerce Developer Agentの設定とテスト

アプリをインストールすると、その制限とメッセージは、誰でも調整できるビジネス設定になります。 この段階では、カート数の上限を設定し、ストアフロントでテストを実施して、ルールが機能することを確認します。

## この動画は誰のためのものでしょうか？

* Commerce開発者
* Commerce管理者
* マーチャンダイザー

## ビデオコンテンツ

* エージェントが公開したビジネス設定（最大カート数と買い物客に接するメッセージ）の確認
* SKUごとの最大カート数をデフォルト値から低い値に下げ、コードを変更せずに保存します
* ストアフロントに商品を追加し、設定された制限を超える
* 再デプロイなしでライブで実行されたブロックと正確なエラーメッセージの確認
