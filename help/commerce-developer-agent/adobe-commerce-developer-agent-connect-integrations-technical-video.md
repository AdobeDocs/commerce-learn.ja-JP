# Adobe Commerce Developer Agent Connectの統合

生成コードには、実行する場所とストアへの接続が必要です。 この段階では、機能が有効になる前に、App Builderでコードをホスティングし、Adobe Commerce インスタンスに接続し、GitHub リポジトリをリンクするなどして、すべてを統合します。

## この動画は誰のためのものでしょうか？

* Commerce開発者
* ソリューションアーキテクト
* バックエンドエンジニア

## ビデオコンテンツ

* Developer Agentが作成したコードをホストするApp Builder プロジェクトおよびワークスペースの作成
* 担当者の足場でプロジェクトを監視し、未解決の設定項目を確認する
* デベロッパーコンソールでの必要なAdobe Commerce as a Cloud Service API資格情報の追加
* 特定のAdobe Commerce Cloud Service インスタンスへのコードの接続
* コードを保存してバージョンを作成するには、GitHub リポジトリをリンクします
